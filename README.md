
#  Caixa Eletrônico em Linguagem C

##  Sobre o projeto

Este projeto consiste no desenvolvimento de um sistema
de caixa eletrônico utilizando a linguagem de programação C.

O sistema simula operações bancárias básicas por meio
de um menu interativo no terminal.

##  Funcionalidades

- [x] Consultar saldo
- [x] Realizar depósitos
- [x] Realizar saques
- [x] Consultar extrato
- [x] Validar valores de operações
- [x] Impedir saques com saldo insuficiente
- [x] Encerrar o sistema

##  Tecnologias utilizadas

- Linguagem C
- GCC (compilador)
- Visual Studio Code (editor recomendado)


##  Como executar o projeto

1. Clone este repositório:

git clone https://github.com/SEU-USUARIO/caixa-eletronico-c.git

2. Entre na pasta:

cd caixa-eletronico-c

3. Compile o programa:

gcc caixa_eletronico.c -o caixa_eletronico

4. Execute:

./caixa_eletronico

No Windows:

caixa_eletronico.exe

##  Demonstração

O programa apresenta um menu interativo com opções
para realizar operações bancárias.

##  Objetivo

Praticar conceitos fundamentais da linguagem C,
como:

- Variáveis
- Estruturas condicionais
- Estruturas de repetição
- Switch case
- Entrada e saída de dados
- Operações matemáticas
